# 얼마벌었지 (Wage Live Tracker)

> 일하는 순간, 돈이 보인다.

시급제 아르바이트 근로자를 위한 Android 실시간 예상 급여 트래커다. 사용자가 출근을 시작하면 현재까지 번 예상 금액을 실시간으로 보여주고, 휴게·야간·연장 등 근무 조건을 반영해 근무 기록과 월간 예상 수입을 관리한다.

## 핵심 목표

- 출근부터 퇴근까지 현재 예상 급여를 실시간으로 확인
- 야간·연장 등 가산 항목을 분리해 계산 근거를 명확히 표시
- 출근 → 휴게 → 퇴근의 단순한 사용 흐름
- 근무 기록을 기기에 저장하고 월간 예상 수입 확인
- 첫 Google Play 출시 및 실제 광고수익 발생 경험 확보

## v1.0 핵심 기능

- 기본 근무조건 설정
- 출근 / 휴게 / 퇴근
- 앱 화면에서 실시간 예상 급여 표시
- 야간근로 및 기본 가산수당 계산
- 근무별 급여 Breakdown
- 근무 기록 수정
- 월간 근무 기록 및 예상 수입
- 진행 중 근무 복구
- 지속 알림 기술 검증
- AdMob 기반 초기 수익화

## v1.0에서 제외

- 회원가입 및 자체 서버
- 클라우드 동기화
- 여러 사업장 관리
- GPS 자동 출퇴근
- 급여명세서 OCR
- 금융기관 연동
- 플로팅 오버레이
- 초단위 홈 화면 위젯
- iOS

## 기술 스택

- Kotlin
- Jetpack Compose / Material 3
- Room
- DataStore
- Coroutines / Flow
- MVVM + Repository
- JUnit
- Google AdMob

현재 Android 프로젝트 기준:

- package: `com.orchid.wagelivetracker`
- minSdk: 26

현재 구현 범위는 급여 계산 엔진, Room 저장, 기본 근무조건 설정과 출근·실시간 급여·휴게·
퇴근 정산, 월간 근무 목록·상세·수정·수동 추가·삭제다. 진행 중 근무와 열린 휴게는
앱 재실행 시 복구한다. 직접 시작한 근무의 지속 알림과 알림 휴게·재개·퇴근을
지원하며 서비스 종료/알림 거부와 관계없이 Room 기록을 보존한다. 광고는 후속 Issue에서 구현한다.
