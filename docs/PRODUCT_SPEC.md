# 제품 기획서

## 1. 제품 정의

**제품명:** 얼마벌었지 (가칭)  
**영문 개발명:** Wage Live Tracker  
**플랫폼:** Android / 대한민국 우선 출시

### 한 줄 소개

출근 버튼을 누르는 순간부터 지금까지 번 예상 급여를 실시간으로 보여주는 알바 급여 트래커.

### 핵심 가치

기존 급여 계산기의 중심이 "근무가 끝난 뒤 계산"이라면, 이 앱은 "근무 중 돈이 쌓이는 경험"을 중심에 둔다.

---

## 2. 대상 사용자

주 2~5회 정도 시급제로 일하는 아르바이트 근로자를 1차 대상으로 한다.

예시:

- PC방
- 편의점
- 카페
- 음식점
- 물류
- 스터디카페
- 야간 및 주말 근무자

---

## 3. 핵심 사용자 흐름

### 최초 실행

앱 설치 → 기본 근무조건 설정 → 홈

### 근무

홈에서 출근 → 실시간 예상 급여 확인 → 필요 시 휴게 → 퇴근 → 정산 확인 → 기록 저장

### 기록

월간 근무기록 → 총 근무시간 / 예상 수입 확인 → 과거 기록 상세 또는 수정

## 5. 급여 계산 원칙

급여 계산 로직은 UI, Room, Android Context와 분리된 순수 Kotlin 도메인 로직으로 구현한다.

### 입력

- 근무 시작 시각
- 계산 기준 시각 또는 종료 시각
- 시급
- 휴게 구간
- 사업장 조건
- 향후 필요한 기타 근무조건

### 출력

- 실제 유급 근무시간
- 기본급
- 야간근로 시간
- 야간가산 예상액
- 연장근로 시간
- 연장가산 예상액
- 기타 지원 가산액
- 총 예상급여

### 실시간 표시

돈을 매초 DB에 누적 저장하지 않는다.

`출근시각 + 현재시각 + 휴게기록 + 적용조건`으로 현재 값을 계산하고 UI만 주기적으로 갱신한다.

### 과거 기록 보존

사용자의 현재 시급이나 근무조건이 바뀌어도 과거 급여가 변하지 않도록 Shift 생성 시 적용 조건의 Snapshot을 저장한다.

---

## 6. 계산 신뢰성

앱은 법률 판단 서비스가 아니라 사용자가 입력한 근로조건을 기준으로 예상 금액을 계산하는 도구다.

각 가산항목에는 가능한 범위에서 계산 근거를 제공한다.

예:

- 야간근로 적용시간
- 적용 시급
- 가산 비율
- 제외된 휴게시간

결과 화면에는 실제 지급액과 차이가 있을 수 있음을 명시한다.

법정 기준은 출시 전 공식 자료로 다시 검증하며, 변경 가능성이 있는 숫자나 조건은 가능한 한 데이터/규칙으로 분리한다.

## 8. 백그라운드/알림

v1.0에서 근무 중 지속 알림을 기술 검증한다.

목표 표시:
- 근무 중 상태
- 경과시간
- 현재 예상 급여
- 휴게/퇴근 액션

Foreground Service 및 Google Play 정책에 대한 검증은 개발 초기에 진행하고, 승인 여부가 앱의 기본 근무기록 기능 자체를 막지 않도록 설계한다.

앱이나 서비스가 종료돼도 Shift와 Break 기록을 기준으로 재실행 시 현재 급여를 복구할 수 있어야 한다.

---

## 9. 광고

근무 중 핵심 흐름을 방해하지 않는다.

광고를 피하는 위치:
- 출근
- 실시간 카운터
- 휴게 시작/종료
- 근무 중 재진입
- 지속 알림

초기 광고 후보:
- 기록/통계 화면의 비침해성 광고
- 퇴근 정산 완료 이후 제한적인 전면광고

첫 수익 목표는 금액 자체보다 실제 출시 → 사용자 → 광고 노출 → 수익 발생의 전체 사이클을 검증하는 것이다.

## 12. 제품 원칙

새 기능은 아래 중 하나 이상을 만족할 때만 우선 검토한다.

1. 출근부터 퇴근까지 사용을 더 편하게 만드는가?
2. 지금까지 번 돈을 더 명확하게 보여주는가?
3. 사용자가 다음 근무에도 앱을 다시 사용할 이유를 만드는가?

v1.0의 최종 목표는 하나다.

> **내가 지금 이 순간에도 돈을 벌고 있다는 것을 눈으로 보여준다.**
