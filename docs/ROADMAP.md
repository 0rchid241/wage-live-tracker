# 개발 로드맵

## v1.0 목표

실제 Google Play 출시가 가능한 최소 제품을 완성한다.

---

## Phase 1 — 급여 계산 엔진

- 순수 Kotlin 도메인 모델
- 기본급 계산
- 자정 통과 처리
- 야간구간 계산
- 휴게구간 제외
- 연장/야간 등 가산항목 구조
- 단위 테스트

완료 기준: Android UI 없이 JVM 테스트만으로 계산 결과 검증 가능.

---

## Phase 2 — 로컬 데이터 계층

- Room 도입
- WorkProfile / Shift / Break 저장
- Repository
- 진행 중 Shift 복구
- 설정 변경 시 과거 조건 Snapshot 보존

---

## Phase 3 — 기본 설정

- 시급 설정
- 사업장 조건 설정
- 선택 근무조건 입력
- DataStore 또는 적절한 저장 계층 적용

---

## Phase 4 — 핵심 근무 흐름

- 출근
- 실시간 예상 급여
- 경과시간
- 휴게 시작/종료
- 퇴근
- 정산 결과
- 근무 저장

이 단계에서 제품의 핵심가치가 동작해야 한다.

---

## Phase 5 — 근무 기록

- 월간 기록
- 월 총 근무시간
- 월 예상 수입
- 개별 근무 상세
- 과거 기록 추가/수정

---

## Phase 6 — 백그라운드/지속 알림

- Foreground Service 기술 검증
- 지속 알림
- 현재 근무 상태 표시
- 알림에서 휴게/퇴근
- 앱 프로세스 종료/재실행 복구
- 기기 재부팅 등 예외 상황 검토

---

## Phase 7 — 품질

- 계산 경계값 테스트
- 앱 상태 복구 테스트
- UI 오류/빈 상태
- 잘못된 시간 입력 방어
- 접근성 및 다크모드 점검

---

## Phase 8 — 출시 준비

- 앱 이름/아이콘 확정
- AdMob
- 개인정보처리방침
- Data Safety
- 스토어 설명 및 스크린샷
- Release build
- Closed Test
- Production 출시 준비

---

## v1.0 완료 조건

- 출근/휴게/퇴근 가능
- 앱 화면에서 실시간 예상 급여 증가
- 기본 급여 및 지원 가산항목 계산
- 근무 Breakdown
- 과거 기록 저장/수정
- 월간 예상 수입
- 진행 중 근무 복구
- 계산 엔진 자동 테스트
- 지속 알림 기술 검증
- 광고 정상 노출
- 출시 필수 문서 준비
- 테스트 트랙에서 치명적 크래시 없음
